A wearable navigation system that turns nearby obstacles and phone commands into directional vibration cues.

I worked on ESP32 firmware connecting Bluetooth commands, ultrasonic sensing, and haptic motor control. The sensor loop stays responsive while measurements are in progress.

ESP32C++BLEUltrasonic sensing
Firmware notes +

The sensor state machine advances over loop passes instead of waiting for an echo in a blocking loop. That leaves time for command handling and motor updates. Packet expiration prevents an old phone cue from remaining active indefinitely.
