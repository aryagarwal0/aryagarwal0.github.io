01 / FEATURED PROJECT

VisionVest

Turning environmental information into touch.

ESP32 firmware for a wearable haptic navigation system, connecting phone commands, ultrasonic proximity sensing, and directional vibration feedback.

ESP32C++BLEState machines
Inside the firmware +

A nonblocking sensor state machine advances measurements across loop passes, allowing command handling and haptic updates to continue while waiting for an echo. Packet expiration prevents stale phone cues from staying active.

02 / ROBOTICS

Vision-Guided
UR3 Drawing Robot

Converting image contours into physical drawings with an OpenCV pipeline, coordinate transforms, inverse kinematics, and ROS motion control.

PythonOpenCVROSUR3
How it works +

Edge detection and contour simplification turn images into waypoints. MoveJ positions the arm between drawing segments; MoveL traces Cartesian paths while position feedback tracks execution.
